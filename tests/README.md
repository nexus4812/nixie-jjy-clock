# 検査・自動試験の計画

資料検査は `python3 scripts/check_phase1.py`。資料の欠落、ローカルリンク、出典ID、BOM金額・数量・価格区分を検査する。加えて全体回路図、共有寸法、機械基板、control-r1の検査を実装済み。各検査の範囲を区別し、調達可能性や実機安全性を検証したものとして扱わない。

Phase 2追加：`scripts/check_hardware.py` は実際のKiCad出力と回路定義を照合する。`scripts/generate_mechanical.py --check` は共通寸法とOpenSCAD定数の一致、`scripts/check_board_envelopes.py` はKiCadで読戻した外形/板厚/穴の一致を確認する。詳細と実施結果は [初版レビュー](../docs/phase2-review.md) を参照。

ファームウェアも試験コードもまだない。Phase 4で純粋ロジックに対して次を実装する。

| 領域 | 擬似入力・期待結果 |
| --- | --- |
| JJYパルス | 0.2/0.5/0.8秒、境界・ジッター・極性反転、欠落・重複・短パルスで誤採用しない |
| フレーム | マーカーの位置、時分の偶数パリティ、BCD各桁、範囲外を検出 |
| 日付 | うるう年の通算日366、平年366の拒否、年末/日跨ぎ、曜日と年の整合 |
| 特殊送信 | 毎時15/45分、うるう秒告知/実施付近で通常フレームとして誤採用しない |
| 補正時刻 | フレーム先頭時刻と取得完了時刻を区別し、1分遅れの補正を防ぐ |
| 信頼判定 | 連続2フレームの分進行、日/年のまたぎを検証。大きな飛びは再取得 |
| RTC | OSF、無効日付、I2C失敗、書込読戻し、復電時に架空の時刻を正常扱いしない |
| 表示 | 00:00、09:59→10:00、23:59→00:00、全数字BCDとコロンの位相 |
| 操作 | ボタンのチャタリング/長押し、設定確定・取消、手動設定後の自動受信 |
| 障害 | JJY永久無信号でもRTC表示継続、タイムアウト/再試行/選局切替、タイマーの周回 |
| 省電力 | 任意の夜間消灯/数字巡回、リセット/受信中からの表示復帰 |

エンコーダーとデコーダーの相互一致だけに依存せず、NICTの公開例を独立した期待値として加える。ISR入力は時刻を注入できるようにし、現実の60秒を待たずに境界条件を試す。

ハードウェアのERC/DRC、ネット/BOM照合、現物寸法、ダミー負荷、高電圧の定格・絶縁・放電・温度、両局の実受信は別の検査票で管理する。自動試験の成功で実測結果を代替しない。

## control-r1追加検査

KiCad対応Pythonで `scripts/check_control_board.py` を実行する。制御板ERC、DRC（警告含む）、回路図等価性、全219パッドのネット、候補フットプリント/配置、共有外形/板厚/穴、RTC禁止領域を確認する。製造承認は常にfalse。`scripts/route_control_board.py` と取り込みスクリプトはDSN/SESのハッシュ対応を確認する。最新の実行記録と再現方法は [HANDOFF.md](../HANDOFF.md) / [保存済み検査記録](../docs/validation/README.md) を参照する。
