# Arduinoファームウェアの方針

ハードウェアはcontrol-r1候補配置/配線まで進んだが、動くスケッチは未作成。最初の対象はATmega328P搭載、5V/16MHzのクラシックNano互換機。販売品を特定してからFQBN、Arduino AVR Boardsの版、書込条件を固定する。

Phase 4ではArduino IDEで開ける `nixie_clock/nixie_clock.ino` を入口にし、JJY復号・日時・状態遷移・表示のロジックをArduino非依存にする。`Wire` と `SPI` を基本にし、RTCはRTClibを評価する。コア/外部ライブラリは固定版を記録する。

## 仮のArduinoピン割り当て

以下はS14で機能を確認したクラシックNano基準の設計案。回路図の割当を反映済み。KiCadネットリストの照合は実施、実機とスケッチの照合は未実施。

| ピン | 機能案 | 注意 |
| --- | --- | --- |
| D0/D1 | USB書込・診断用に予約 | 外部回路を接続しない案 |
| D2 | バッファ後のJJYエッジ入力 | 内部プルアップ禁止、反転極性を正規化 |
| D3 | DS3231 SQW | 外部プルアップ、1Hzを設定 |
| D4/D5 | PDN1/PDN2制御 | 3Vへの変換段経由、反転を明記 |
| D6 | HV許可 | ハードウェア初期OFFを別途設計 |
| D7 | ネオンコロン | HVトランジスター経由 |
| D8 | 予備 | Phase 2初版では595 OEをGNDへ固定。データ確定前はHVを許可しない |
| D9 | 状態LED | 抵抗を介して駆動 |
| D10 | 595 RCLK | SPI転送後に一括ラッチ |
| D11/D13 | SER/MOSI、SRCLK/SCK | 2段595。D13の内蔵LED等の負荷も確認 |
| A0/A1/A2 | SET / + / - | 低電圧ボタン、デバウンス |
| A4/A5 | DS3231 SDA/SCL | 5V系I2C、初期100kHzを候補 |

D12、A3等を予備とする。A6/A7をデジタルボタン用途として割り当てない。最終割当は回路図と1か所の定義ファイルを正本にし、変更時に配線・試験・操作説明を更新する。

JJYのISRはエッジ時刻記録だけに絞り、I2C・表示更新・ログ・ボタン処理をISRで行わない。受信中もRTCを読んで時計を進め、受信失敗は有限時間で終了する。詳細は [実装計画](../docs/implementation-plan.md) と [試験計画](../tests/README.md) を参照。
