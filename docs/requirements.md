## 使用・表示動作の提案

- 時刻・日付はJSTで保持し、DS3231は24時間モード。JJYの西暦下2桁は2000〜2099年として扱う案で、年の扱いをテストで固定する。
- `SET / + / -` の3ボタン。長押しで設定へ入り、時・分と必要な日付を設定できるようにする。表示は4桁なので日付は順番に編集する案。
- 状態は `RTC_INVALID / RTC_ONLY / RECEIVING / SYNCED / STALE` を区別する。LEDの点滅パターンと対応表を用意する。
- 有効なRTCがない起動時は架空の時刻を表示しない。管を消灯し状態LEDで設定待ちを知らせる。
- 初回未受信でも手動設定後は時刻表示を続ける。最新JJY成功日時を保持し、古い成功を「現在同期済み」と誤認させない。
- 自動受信は夜間の静かな時間帯に有限回、40/60kHzを順番に試す。具体的な時間、タイムアウト、消灯の許容時間はR09で調整する。
- 管の数字巡回は寿命を保証するものではない。表示電流・時間を守り、劣化した管への過大電流による復活処理は仕様に入れない。
