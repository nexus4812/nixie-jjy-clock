# 低電圧制御板 control-r1

2026-11-08、状態：候補フットプリント・現物未照合・製造不可。再開手順と環境は [HANDOFF.md](../HANDOFF.md) に集約する。

[KiCadプロジェクト](../hardware/pcb/generated/control-board.kicad_pro) は6ページの制御用回路図と2層PCBを含む。全体回路図は11ページ/111部品で、うち54部品をこの基板へ配置した。外部に置くモジュール/ボタン/LED、HV電源/表示管/ドライバー/ネオンは制御PCBに含めない。装置全体は共通GND。

## 元データ・候補部品

- 回路の正本は `hardware/schematic_design.py`、配置/候補フットプリント/配線条件は `hardware/pcb/control_layout.json`。外形/厚み/穴は `enclosure/layout.json`。
- Nano互換ATmega328P 5V/16MHz、Nexperia `74HCT595D` ×2（S05）、`DS3231SN#`（S06）、`MCP1700-3002E/TO`（S33）、`SN74HCT125D`（S32）、Keystone 1060候補（S40）。抵抗/セラミックは0805、TO-92はWide、基板側ヘッダーは2.54mm。
- 595/HCT125のSOICはメーカー資料のパッケージ候補。標準フットプリントはKiCad10.0.8導入版から取得し、全ピン番号を照合した。ライブラリIDと取得元ファイルSHA-256は `board-generation.json`。ライブラリの利用条件はS39。
- 電池ホルダーの原図/極性と実物、Nano互換のUSB/電源/ソケット高さ、TO-92のリード成形、受動部品の有効容量/定格は未確定。存在する標準フットプリントを読み込めたことと現物への適合は別。

## 外部接続

| 基板側 | ピン順 | 用途 |
| --- | --- | --- |
| J41 | 1=5V_BUCK、2=GND | 既製降圧器からの5V。JP1はUSB時に開放する案 |
| J42 | GND / HV_ENABLE / COLON_ENABLE | 別板のトランジスターへ渡す論理出力。HV/12V端子ではない |
| J50〜J53 | +5V / GND / BCD bit0 / bit1 / bit2 / bit3 | 各表示板のJ10〜J13へ |
| J45 | +3V_JJY / GND / PDN2 / OUT_RAW / PDN1 | 外置き受信モジュール。2.54→実モジュール2.5mmのハーネスが必要 |
| J40 | GND / BUTTON_SET / BUTTON_PLUS / BUTTON_MINUS / LED_ANODE | 背面操作部 |
| J3 | +5V / GND / SDA / SCL | I2C診断 |
| J4 | +3V_JJY / OUT_RAW / JJY_DATA | 受信信号のバッファ前後診断 |

JP1だけで全互換機のUSB逆給電や装置の初期OFFを保証していない。実回路/接続状態/起動/停止でR11を確認する。

## 配置・配線条件

外形100×55mm、厚み1.6mm、穴φ3.2mmを(4,4)/(96,4)/(4,51)/(96,51)へ配置。ねじ頭の予約は標準MountingHoleのcourtyardを使用する。実際の固定具/ケースとの3D適合は未検証。

RTC直下7.8×10.6mmは両銅箔面の配線/ビア禁止、パッドは許可。VBAT引き出しは正本に5セグメントの種配線として定義した。GNDベタ、シールド、EMC/受信品質の検証は今後行う。

DRC設定はクリアランス0.25mm、最小線幅0.20mm、通常0.25mm、ビア径0.8mm/穴0.4mm、銅箔-外形0.5mm。自動配線へは間隔0.30mmを与え、取り込み後に最小0.20mmへ拡幅して実銅箔を再検査した（76セグメント）。これは低電圧制御板の加工上のルールで、HVの絶縁距離ではない。

Freerouting 2.5.0 JVMをローカルで使用（S37/S38）。JARは公式digestと照合。DSNとSESの対応ハッシュを保存し、違う入力のSESを拒否する。ルーター終了0や「未配線0」という自己判定だけでは合格にしない。KiCadで保存後のERC/DRC/等価性を再確認する。
