- 回路図/PCB/確定BOMの部品番号・ネット・フットプリントが一致し、ERC/DRCの未解決項目が説明されている。

- JLCPCBの加工条件、層/板厚/銅厚/表面処理、注文枚数、送料を見積で確認している。
- Gerberと穴あけデータを別ビューアーで確認し、層、原点、外形、表裏、穴とランドの対応を検査している。

実装後は低電圧のみから段階通電し、HVダミー負荷、単管、全管、受信の順に進める。通電前の具体的な測定値・合否基準は最終回路が決まってから作成する。製造ファイルの出力成功と、安全に動く完成品の確認は別の記録にする。
